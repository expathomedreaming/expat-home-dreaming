# 🌍 Expat Home Dreaming — Setup Guide ## Go from zero to live website in about 30 minutes --- ## What you're setting up ``` GitHub (stores your files) ──► Netlify (hosts your website) ──► yoursite.com (live!) ▲ Admin panel (you add listings here) ``` --- ## STEP 1 — Create a GitHub account (5 minutes) 1. Go to **https://github.com** 2. Click **"Sign up"** (top right) 3. Enter your email, create a password, choose a username 4. Verify your email address 5. On the "What are you interested in?" screen, you can skip everything — just click **Continue** ✅ You now have a GitHub account. --- ## STEP 2 — Create your website repository (5 minutes) A "repository" is just a folder on GitHub that holds your website files. 1. Once logged into GitHub, click the **"+"** icon (top right) → **"New repository"** 2. Repository name: `expat-home-dreaming` 3. Make sure **"Public"** is selected (required for free Netlify hosting) 4. Check **"Add a README file"** 5. Click **"Create repository"** (green button) ✅ You now have an empty project on GitHub. --- ## STEP 3 — Upload your website files (5 minutes) 1. On your new repository page, click **"Add file"** → **"Upload files"** 2. Drag ALL the files/folders from the zip you downloaded into the upload area: - `index.html` - `netlify.toml` - `admin/` folder (with `index.html` and `config.yml` inside) - `listings/` folder (with all the `.md` files inside) - `images/` folder 3. Scroll down, leave the commit message as-is, click **"Commit changes"** ⚠️ **Important:** Make sure the folder structure looks like this in GitHub: ``` expat-home-dreaming/ ├── index.html ├── netlify.toml ├── admin/ │ ├── index.html │ └── config.yml ├── listings/ │ ├── provencal-farmhouse-france.md │ └── (other listing files) └── images/ └── uploads/ ``` ✅ Your files are now on GitHub. --- ## STEP 4 — Create a Netlify account and connect GitHub (5 minutes) 1. Go to **https://netlify.com** 2. Click **"Sign up"** → choose **"Sign up with GitHub"** (easiest — links them automatically) 3. Authorize Netlify to access your GitHub 4. On the Netlify dashboard, click **"Add new site"** → **"Import an existing project"** 5. Click **"Deploy with GitHub"** 6. Find and click your `expat-home-dreaming` repository 7. Leave all settings as defaults — click **"Deploy site"** Netlify will build and publish your site. This takes about 60 seconds. ✅ Your site is now live! Netlify gives you a URL like `amazing-cupcake-123456.netlify.app`. --- ## STEP 5 — Enable the admin panel (5 minutes) The admin panel lets you add listings without touching any code. You need to enable "Netlify Identity" for it to work. 1. In Netlify, go to your site dashboard 2. Click **"Integrations"** in the top menu 3. Search for **"Identity"** → click **Enable** 4. Go to **Identity** → **Settings** → under **"Registration"**, set it to **"Invite only"** 5. Go to **Identity** → click **"Invite users"** → enter your own email 6. Check your email — click the invite link and set a password 7. Visit `https://your-site-url.netlify.app/admin` 8. Log in with your email and password ✅ You can now add listings through the visual admin panel! --- ## STEP 6 — Get a custom domain (optional, ~10 min + $12/year) 1. Buy a domain at **https://namecheap.com** (e.g. `expathomed reaming.com`) 2. In Netlify → **Domain management** → **Add custom domain** 3. Follow Netlify's instructions to point your domain to Netlify 4. Netlify sets up HTTPS (the padlock) automatically for free --- ## 📝 How to add a new listing Once your site is live: 1. Go to `https://your-site-url.netlify.app/admin` 2. Log in 3. Click **"New Listings"** 4. Fill in the form: title, price, location, region, bedrooms, photo, description 5. Click **"Publish"** 6. Your site automatically rebuilds in about 60 seconds — the listing appears! --- ## 🖼 Adding a photo to a listing In the admin panel, when you get to the **"Hero Photo"** field: - Click **"Choose an image"** - Click **"Upload"** to upload a photo from your computer - The photo gets stored in your GitHub repository automatically **Tip:** Before uploading, resize photos to about 1200px wide using a free tool like https://squoosh.app — this keeps your site fast. --- ## ❓ Common questions **Q: I uploaded files but my site shows a blank page** A: Make sure `index.html` is at the root of your repository (not inside a subfolder). **Q: The admin panel says "Not Found"** A: Double-check that the `admin/` folder with `index.html` and `config.yml` was uploaded correctly. **Q: My changes aren't showing up** A: Netlify takes 30–90 seconds to rebuild. Check the "Deploys" tab in Netlify to see if it's still building. **Q: Can I add more listings?** A: Yes! Just use the admin panel. Each new listing you save automatically creates a new `.md` file in your GitHub repository. --- ## Need help? If you get stuck, copy the error message and ask Claude: "I'm setting up Expat Home Dreaming on Netlify and I'm seeing this error: [paste error]"
